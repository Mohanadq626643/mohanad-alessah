# استوديو الكليب الكرتوني — «شفت كلام»

أداة تعمل في المتصفح (بدون اعتماديات) تحوّل أغنية وكلماتها العربية إلى فيديو كليب كرتوني متزامن.

## التشغيل
```bash
npm start          # ثم افتح http://localhost:5173
npm test           # اختبارات التحليل والمحاذاة واختيار المشاهد
npm run test:e2e   # اختبار شامل في Chromium: تحليل، رسم كل المشاهد، مزامنة بالنقر، تصدير WebM وفحصه بـ ffprobe
```

## خطوات العمل
1. **ملف الأغنية**: يُحلَّل داخل المتصفح (Web Worker): الإيقاع BPM، الضربات وبدايات المازورة، الضربات القوية، مناطق الغناء (بفصل المنتصف/الجوانب في الستيريو + عتبة Otsu)، وفترات الصمت.
2. **الصورة المرجعية**: حدّد منطقة العيون بالسحب؛ تُرسم داخل عيون الشخصية الكرتونية (مع رمش ونظر وجفون) في كل المشاهد.
3. **الكلمات**: الصق النص الصحيح (سطر لكل جملة) أو ملف **LRC** (يدعم توقيت كل كلمة `<mm:ss.xx>`). لا تُخمَّن الكلمات أبدًا.
4. **التوقيت**:
   - *محاذاة تلقائية* = **تقدير** (مخطط بالبرتقالي) يوزّع الأسطر على مناطق الغناء المكتشفة، والكلمات على زمن الغناء الفعلي مع الالتصاق بالضربات.
   - *مزامنة بالنقر*: اضغط المسافة مع بداية السطر وارفع عند نهايته (أو لكل كلمة) أثناء الاستماع → «مؤكد».
   - سحب حواف الأسطر على الخط الزمني أو تعديل الأرقام مباشرة → «مؤكد».
5. **المشاهد**: يُقترح مشهد لكل سطر من معنى كلماته (عيون، كلام، هاتف، ليل، بحر، مطر، طريق، قلوب، مدينة، مسرح، وقت، صحراء، نار، شروق) مع منع التكرار المتتالي، ويمكن تغييره. إضافةً إلى مقدمة وفاصل موسيقي للفجوات الطويلة وخاتمة.
5ب. **الإخراج** (من بطاقة «الإخراج»):
   - **مكان واحد يتحوّل مع المعنى** (افتراضي): غرفة ليلية ثابتة بتفاصيل وإضاءة، وكل سطر يغيّر عناصرها بدل القطع: لون الضوء يمتزج نحو مزاج جديد، شاشة التلفاز تبدّل أيقونتها مع تشويش القناة، منظر النافذة يتغير (مطر، بحر، شروق…)، صاحب الصورة يخرج من إطاره ويعود، قلب يتوهج، دمعة، الساعة تدور، والكاميرا تقترب من العينين.
   - **مشاهد كرتونية متعددة**: مشهد مختلف لكل سطر مع انتقالات على الضربات.
   - المقاس: **عمودي 9:16** (افتراضي) أو أفقي 16:9. عرض الكلمات: **الجملة كاملة** أو **كلمة بكلمة**.
6. **التصدير**: فيديو WebM (720p/1080p بالمقاس المختار) مع الصوت، ملف مشروع JSON، أو LRC.

## البنية
- `src/audio/analysis.js` تحليل الصوت (FFT، spectral flux، تتبع الضربات Ellis DP، كشف الغناء).
- `src/lyrics/` تحليل الكلمات/LRC، المحاذاة (برمجة ديناميكية)، القاموس الدلالي للمشاهد.
- `src/render/` المشاهد، الشخصية والعيون، النص العربي المتحرك (كل كلمة تُرسم كاملة فيبقى اتصال الحروف سليمًا)، الانتقالات الملتصقة بالضربات.
- `src/ui/` الواجهة، الخط الزمني، محرر القص.

الخطوط: Lalezar و Cairo (رخصة SIL OFL، في `assets/fonts`).
